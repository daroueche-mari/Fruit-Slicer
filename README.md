# Fruit-Slicer
🍎 Fruit Ninja Ultimate - Typing Edition
Une version revisitée du célèbre jeu Fruit Ninja, alliant réflexes et dactylographie. Tranchez des fruits en tapant les lettres correspondantes sur votre clavier et survivez aux vagues de plus en plus rapides !

🎮 Fonctionnalités principales
Gameplay aux touches : Chaque fruit possède une lettre unique. Appuyez sur la touche correspondante pour le trancher.

Système de Bonus Varié :

∞ Loto (Mode Dictionnaire) : Tranchez le fruit "Infini" pour figer le temps. Saisissez des mots valides du dictionnaire pour accumuler des points bonus.

❄️ Ice Block : Ralentit considérablement tous les objets à l'écran et vous protège contre la perte de vies.

🌀 Shuriken (Spinner) : Déclenche une attaque spéciale qui tranche instantanément tous les fruits visibles.

✨ Fruits Dorés : Des fruits enrobés d'un halo d'or qui demandent deux frappes et déclenchent une explosion combo.

Difficulté Progressive : La vitesse de spawn et de chute des fruits augmente à mesure que votre score grimpe.

Effets Visuels : Système de particules, secousses d'écran (screen shake) lors des explosions, et débris de fruits réalistes.

🚀 Installation & Lancement
Assurez-vous d'avoir Python et Pygame installés.

Placez vos assets (images .png) dans le même dossier que le script.

(Optionnel) Créez un fichier mots.txt contenant un mot par ligne pour personnaliser le mode Loto.

Lancez le jeu :

Bash
python fruit_ninja.py

🛠️ Technologies utilisées
Langage : Python 3

Bibliothèque : Pygame
